# 추억 수첩과 선택형 만남

2026-11-05 구현. 캐릭터를 키운 뒤에도 할 일이 보이도록 기존 18종의 성격·역할에 맞는 선택형 만남을 추가했다.

- 각 종에 질문 1개, 선택지 3개, 짧은 결말과 추억 카드 1장. 총 18개 만남과 18장 카드.
- 정원에서 날짜에 따라 보유 친구 한 명을 소개한다. 추억 메뉴에서는 보유 친구 누구든 바로 만날 수 있다. 날짜 변경은 콘텐츠 잠금이나 보상 리셋 조건이 아니다.
- 알 부화·돌봄·성장·서식지·친구 관계·추억 수집을 연결한 달성 목표 10개. 저장된 사실로 계산하므로 기존 진행에도 소급 표시한다.
- 틀린 선택에는 시간·재화·성장 손실이 없다. 다시 고를 수 있다. 기록된 카드는 다시 획득하지 않는다.
- 아직 없는 친구는 도감으로 연결하며, 만남만으로 미보유 종을 획득하지 않는다.
- 저장에 선택적 memories ID 목록을 추가했다. 이전 저장은 그대로 읽으며 미보유·중복·잘못된 형식의 추억 기록은 가져오기에서 거부한다.

검증: 자동 테스트 36개 통과. 실제 Mac 설치 앱에서 모루잎 만남 → 재선택 안내 → 햇살 한 조각 획득 → 추억 수첩 1/18 표시를 확인했다. 검증 과정에서 로컬 일반 정원에 모루잎 추억 카드 한 장을 기록했다. 모든 만남의 반복 획득 방지와 저장 왕복은 자동 테스트로 확인했다. 전체 18종의 GUI 플레이테스트는 아직 하지 않았다.

이번 콘텐츠는 짧은 선택형 이야기다. 전투·탐험·상점·장비 시스템은 구현 범위에 포함되지 않는다. 다음 확장은 만남에서 캐릭터 고유 동작이 보이도록 하는 연출과 달성 목표에 따른 정원 꾸미기 보상이 적합하다.
