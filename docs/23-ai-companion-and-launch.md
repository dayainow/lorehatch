# Moamon — AI 작업 동료와 공개 알파 계획

2026-11-04. 제안과 현재 구현을 구분한다. 현재 앱은 집중 타이머 기반이며 AI 사용량 연동은 아직 구현하지 않았다.

## 제품의 한 문장

제안 영문 메시지: **Your AI work, a little more alive.**

설명: **A tiny desktop companion that grows alongside your AI coding sessions.**

한국어: **AI와 일하는 동안, 책상 위 작은 친구가 자라요.**

몬스터 이미지를 매번 모델로 생성하거나 사용자를 대신해 유료 API를 호출하는 제품이 아니다. 이미 사용 중인 AI 도구의 활동을 독립 창작 캐릭터의 성장에 연결한다. 현재 18종과 관계 이야기 9편을 유지한다.

## 참고한 제품

[PokeTokenBar](https://github.com/chattymin/PokeTokenBar)는 메뉴바 펫, AI 사용량, 도감이라는 세 가지를 첫 문장에서 연결한다. README는 사용 과정, 실제 UI, 도구별 지원, 직접 다운로드 순으로 구성한다. 로컬 사용 로그와 공급자별 연동을 사용하며 일부 기능은 네트워크와 인증 정보에도 접근한다. 모아몬에는 그림·캐릭터·문구·코드를 복사하지 않는다.

## 성장 입력 선택

추천 기본 방향은 사용자가 한 번 연결한 AI 도구의 활동을 자동 반영하는 Mac 모드다. 기존 수동 집중 모드는 유지한다.

- AI 활동 모드 — 연결한 공급자의 새로운 사용량 이벤트가 있는 시간 구간을 성장으로 환산한다. 큰 컨텍스트·비싼 모델·캐시 토큰이 많은 사용자에게 과도한 이점을 주지 않는다.
- 컴퓨터 활동 모드 — 후속 후보. 마지막 입력 이후 유휴 시간과 잠금·잠자기 상태로 활동 여부만 판단할 수 있다. CPU 사용률은 생산적인 작업의 대리 지표로 쓰지 않는다. 읽기·영상 회의처럼 입력이 적은 작업은 잘못 쉬는 시간으로 판단할 수 있다.
- 수동 집중 모드 — 현재 구현. AI 도구를 연결하지 않는 사람도 계속 플레이할 수 있다.

첫 연동 범위는 한 공급자의 로컬 사용량 이벤트만으로 제한한다. 공급자별 실제 이벤트 형식과 현재 지원 API를 검증한 후 구현한다. Codex와 Claude Code는 후보이며 지원 완료 목록으로 표시하지 않는다.

## 자동 성장의 최소 구현 기준

1. 설정에서 공급자·읽을 위치·처리할 필드를 설명하고 사용자가 연결한다. 시작 버튼은 매번 누르지 않아도 된다.
2. 최초 연결 때 기존 로그 위치를 기준점으로 삼는다. 과거 전체 사용량을 갑자기 성장으로 적립하지 않는다.
3. 새 이벤트의 시각·공급자·사용량만 처리한다. 프롬프트·응답·파일 경로·API 키는 보관하거나 전송하지 않는다. 대화가 포함된 파일을 읽는 경우 그 사실을 동의 화면에 설명한다.
4. 안정적인 이벤트 식별자로 중복을 막고, 파일 이동·축소·회전·앱 재시작 때 재적립하지 않는다.
5. 같은 시간 구간의 여러 공급자와 수동 집중을 겹쳐 더하지 않는다. 하루 한도는 유지한다.
6. 창을 닫아도 네이티브 수집기가 활동을 처리하고, 화면에서는 저장된 성장 상태를 읽는다. WebView 타이머만으로 백그라운드 기능을 구현하지 않는다.
7. 파일을 읽을 수 없거나 형식이 바뀌면 이유와 마지막 갱신 시각을 표시하고 수동 모드를 제공한다.
8. 연결 해제 즉시 읽기를 중단한다. 인증 정보·키체인·공식 요금/한도 조회는 첫 버전 범위에서 제외한다.

활동 구간 길이와 성장 환산율은 아직 결정하지 않았다. 현재 data/balance.json의 시간 수치를 임의로 토큰 단위로 바꾸지 않는다. 실제 이벤트 fixture로 중복·재시작·날짜 변경·오래된 로그·손상된 줄·복수 공급자 겹침을 먼저 검증한다.

## 사용자의 다운로드 경로

현재 공개 브라우저 알파와 소스 ZIP만 제공한다. 설치된 로컬 Mac 앱은 다른 사용자가 GitHub에서 받을 수 있는 릴리스가 아니다.

첫 배포는 GitHub Releases의 명시적인 **macOS alpha**로 제공한다.

1. 코드·문서·동일 빌드 아티팩트를 한 버전으로 고정한다.
2. `Moamon-<version>-macOS-universal.zip`, SHA-256 체크섬, 영문·한국어 설치 안내, 알려진 제한을 준비한다.
3. 깨끗한 Mac 환경에서 압축 해제·실행·저장·재실행을 검증한다. 서명·공증 여부를 릴리스 상단에 정확히 명시한다.
4. 공개 릴리스를 게시한 뒤 README의 다운로드 버튼을 그 아티팩트로 연결하고 실제 다운로드를 확인한다.
5. 사용자는 다운로드 → 압축 해제 → 앱을 Applications로 이동 → 실행 순서로 설치한다. 시스템 보호 기능을 끄는 명령은 제공하지 않는다.

커뮤니티 유입 전에 영어 게임 화면과 첫 실행 안내가 필요하다. 영어 README만으로 영어 게임 지원을 주장하지 않는다.

## 공유 설계

게임의 공유 카드는 선택한 파트너·성장 모습·발견한 종 수·친구 이야기 수·Moamon 이름과 프로젝트 주소를 담는다. 토큰 비용, 작업 내용, 회사·프로젝트 정보, 사용자 별명은 기본 제외한다.

공유는 사용자가 버튼을 누를 때 이미지 저장 또는 링크 복사로 시작한다. 커뮤니티 자동 게시·계정 접근·반복 홍보는 하지 않는다.

실제 alpha 다운로드가 생긴 뒤 쓸 영문 초안:

> I’m building Moamon, a small pixel-pet garden for your Mac. Choose an egg, raise an original creature, and discover little stories between friends. The current alpha has 18 species and a floating desktop companion. I’m exploring an opt-in AI activity mode so it can grow alongside coding sessions. I’d love feedback on the first-run experience and which creature you’d pick.

한국어 초안:

> 맥 화면 위에서 작은 친구를 키우는 모아몬을 만들고 있어요. 현재 18종을 키우고 친구 사이의 짧은 이야기를 발견할 수 있습니다. 다음에는 AI 작업 활동과 성장을 연결하려고 해요. 첫 실행에서 헷갈리는 부분과 만나보고 싶은 캐릭터에 대한 의견을 듣고 싶습니다.

게시 시 실제 릴리스 링크, 게임 지원 언어, 서명 상태를 덧붙인다. AI 연동 구현 후에는 “exploring”을 실제 지원 공급자와 검증된 동작 설명으로 교체한다. 커뮤니티별 홍보 규칙을 확인한 뒤 개발자가 직접 올린다.

## 구현 진행 업데이트

Claude Code Stop 명령 훅으로 완료 시각만 전달하는 첫 어댑터를 구현했다. 1분 구간마다 성장 시간 1분을 주며 실제 작업 시간이나 토큰 사용량을 측정하지 않는다. 대화 로그 스캔 대신 명시적으로 설치한 훅을 사용한다. [설정과 현재 검증 한계](24-ai-activity.md)를 따른다. 위의 전체 연동·배포 계획이 완료되었다는 뜻은 아니다.
