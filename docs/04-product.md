# 제품·화면·성장 규칙

## 제품 약속

작업하는 동안 옆에서 자라는 작은 동료. 일이 늘어나는 게임이 아니라, 짧게 확인하고 일상으로 돌아가는 수집 경험. 집중력 향상 효능은 주장하지 않는다.

## 반복 흐름

**알 선택 → 품기 → 부화 확인 → 아기 환수와 함께 시간 보내기 → 성장 확인 → 도감 등록 → 다음 알.**

알은 한 번에 하나, 육성 대상도 하나. 부화하면 자동으로 현재 육성 대상이 된다. 성장한 환수는 정원에 남고 언제든 화면 동료로 선택 가능하다. 화면 동료와 육성 대상은 별개다. 팝오버에 ‘지금 자라는 환수’를 명시해 좋아하는 성장형을 띄워둔 상태에서도 진행 대상을 알 수 있게 한다.

탐방, 흔적 수집, 퀘스트 게시판, 행동 관찰 과제는 MVP에서 제거한다. 클릭 돌봄은 귀여운 반응만 주고 성장의 필수 노동이나 추가 재화가 아니다.

## 처음 5분 — 제안

1. 로그인 없이 실행. 숲용·날개말·세머리 강아지 알에서 하나 선택. 첫 알은 결과를 명시.
2. 첫 알만 ‘처음 만나기’ 체험으로 즉시 부화. 유료 자원이 아닌 튜토리얼 예외.
3. 별명은 선택 사항. 화면 동료와 도감의 아기 모습 등록.
4. ‘함께하기 시작’으로 시간을 누적. 10/25/50분 타이머 또는 사용자가 중지하는 자유 세션.
5. 앱은 작게 머물고 부화/성장 완료는 사용자가 확인할 때 재생. 자동 포커스 이동 없음.

## 시간 규칙 — 구현 전 튜닝 가설

- 재화 하나: 온기. 사용자에게는 ‘함께한 시간’으로 표현. 유료 구매 불가.
- 실행 중 사용자가 시작한 세션 1분 = 온기 1. 원본 계산은 초 단위, 표시만 분 단위.
- 첫 알: 즉시 부화하는 1회 예외. 이후 알: 온기 25.
- 아기 → 성장: 해당 개체에 온기 75. 총 1회 성장으로 MVP 단순화.
- 10/25/50분 선택과 무관하게 같은 실제 누적 시간은 같은 진행을 줌. 짧은 세션 반복 보너스 없음.
- 일일 적립 상한 150분을 초기 후보로 설정. 상한 뒤에도 함께하기·꾸미기 가능. 과도한 사용을 보상하지 않음.
- 앱 종료·수면·일시정지 중 적립 없음. 오프라인 보상 없음. 작업 내용이나 키 입력으로 ‘진짜 집중’을 판정하지 않음.
- 임계값을 넘긴 활성 세션의 잔여 온기는 은행에 보관. 한도 내 적립을 잃지 않으며 사용자가 다음 대상 선택/확인 시 사용.
- 성장 완료 후 다음 알을 바로 고를 수 있음. 조작 지연 때문에 온기가 사라지지 않음. 온기 상한과 튜토리얼 플래그는 저장.
- MVP 3종에서 첫 종 75 + 다음 2종×(25+75) = 총 275분에 모두 성장 가능. 약 4시간 35분이며 실제 앱 사용량에 따른 값. 작은 시험 콘텐츠이므로 장기 잔존을 증명하지 못함.

이 수치는 `data/balance.json`에 명시한다. 실제 참여 부담을 보고 변경하며 테스트에서 일일 상한/성장 시간을 고정 진실처럼 다루지 않는다.

## 알과 중복

MVP는 미보유 종의 알 중 직접 선택, 중복 없음. 선택 화면에는 해당 환수 미리보기와 성장 실루엣을 보여줌. 첫 기대감은 결과 도박보다 부화 연출과 성장 모습에 둔다.

10종 확장 후에는 미보유 종 중 ‘깜짝 알’을 선택적으로 도입할 수 있다. 중복 방지, 결과 풀 공개, 유료 뽑기 없음. 초기 확정 선택 방식을 대체하지 않는다. 희귀 색·성격 랜덤·분기 성장도 MVP 뒤로 미룬다.

## 화면과 기본 문구

- 메뉴바: 작은 알/환수 아이콘, 누르면 상태창. 설정에서 아이콘만 표시 가능.
- 상태창: ‘날개말이 자라고 있어요’, 시간 진행, 시작/일시정지, 도감/정원 버튼.
- 데스크톱 동료: 2× 또는 3× 정수 확대. 드래그, 숨김, 우클릭 메뉴. 클릭하면 짧은 반응.
- 알 선택: 3개 선택지와 예상 시간. 완료 연출은 ‘알이 깨어날 준비가 됐어요 → 만나기’.
- 도감: 미보유 실루엣, 아기/성장 전환, 별명·날짜, 접힌 전승 설명. 문구 ‘3종 중 1종을 만났어요’.
- 정원: 배경 하나, 보유 개체 선택. MVP에는 꾸미기 상점 대신 기본 소품 3개만 제공. 자유 배치 편집기는 후속.
- 설정: 소리 기본 끔, 알림 선택, 동작 줄이기, 자동 시작 기본 끔, 데이터 내보내기/가져오기/삭제.

## 첫 주의 경험

첫날: 첫 부화와 첫 성장의 기쁨. 다음 접속: 좋아하는 성장형을 옆에 두고 둘째 알. 3종 완료: 정원 단체 장면과 도감 공유 이미지. 콘텐츠 완성 후에도 기존 동료와 함께할 수 있음. 미접속 벌점·사망·출석 초기화 없음.

## 범위 밖

전투·교배·탐방·거래·랭킹·AI 채팅·AI 로그 수집·실시간 동기화·결제·유료 가챠. Chrome 확장 동시 출시도 제외. 성장 규칙의 재미가 확인된 후 각각 비용 대비 가치를 판단한다.
