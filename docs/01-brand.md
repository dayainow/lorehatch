# 브랜드와 네이밍

## 브랜드 약속

“당신의 하루 곁에서, 오래된 이야기가 작은 생명으로 깨어납니다.”

고객은 신화 지식을 시험받거나 환수를 계속 관리할 필요가 없다. 짧게 시작하고 일상으로 돌아오면, 다음 만남과 관찰 기록이 기다린다. 귀여움에 작은 신비감을 더하되 어두운 전쟁 판타지나 영유아 장난감처럼 보이지 않게 한다.

## 추천 작업명: Lorehatch / 로어해치

Lore(전승·이야기) + hatch(깨어나다·부화하다)의 조합. 특정 국가, 신, 동물, AI 제품 이름에 묶이지 않아 지역 확장과 협업에 유리하다. 모든 환수가 생물학적 알에서 태어난다는 뜻은 아니며 브랜드 차원에서 이야기의 깨어남을 표현한다.

- 표기: Lorehatch. 한글: 로어해치. 저장소 식별자: lorehatch.
- 한국어 태그라인: **전설이 쉬어 가는 작은 보호구역.**
- 영어 태그라인: **A little sanctuary for living legends.**
- 기능 설명: 신화에서 영감을 받은 환수를 만나는 데스크톱 보호구역.
- 짧은 소개: 일하는 동안, 다음 전설이 깨어납니다.
- 앱 내부 공간명: 보호구역 / 관찰 도감 / 탐방길 / 이야기 조각.
- 장점: 발견·육성 암시, 지역 확장성, 제목 자체의 이야기.
- 약점: Lore가 한국어 사용자에게 생소할 수 있음. ‘로어해치’ 듣고 영문을 쓰기 어려울 수 있으며 ‘해치’가 한국 전설의 해치로 오해될 수 있음. 첫 소개에는 기능 설명을 함께 사용한다.

## 대안 후보

### Mythnook / 미스눅

신화 + 아늑한 구석. 화면 구석에 놓는 제품과 잘 맞는다. 다만 발음과 철자 기억이 약하고 육성 기능이 잘 전달되지 않는다. 2순위 후보.

### 설화숲

한국어 정서가 좋고 세계 여러 이야기를 담을 수 있다. 전 세계 제품의 영문 이름을 별도로 고민해야 하며 이름의 식별력과 선행 사용은 미검증. 한국어 중심 서비스를 택하면 재검토.

### Mythaven / Mythhaven

뜻은 맞지만 비슷한 이름의 Steam 게임 및 별도 사업체가 확인되어 제외. 좁은 검색에서 충돌 신호가 나온 후보를 고집하지 않는다.

### 설화원

한국관광공사에 동명 관광지가 있고 기타 동명 사용도 검색되어 제외. 검색 결과에서 제품을 구분하기 어렵다.

## 이름 검증 상태 — 2026-10-26

정확 문자열 Lorehatch, 로어해치, Mythnook 등을 제한적으로 웹 검색했다. 반환 결과에서 뚜렷한 동일 제품을 식별하지 못했지만 검색 누락 가능성이 있어 사용 가능 판정은 아니다. Mythaven 및 설화원은 충돌 사례를 확인했다. 도메인, 앱스토어, Chrome Web Store, Steam, 소셜 계정, KIPRIS/WIPO/진출 국가 상표 검색은 미완료.

출시 확정 전 5명 이상에게 이름을 읽게 하고, 들은 이름을 다시 입력하게 한다. 정확한 발음·철자 회상이 절반 미만이면 이름을 수정한다. 이 기준은 작은 표본의 내부 판단 기준일 뿐 통계적 시장 검증이 아니다.

## 시각 방향 — 제안

- 기본 톤: 이끼색, 양피지색, 어두운 잉크색. 각 서식지에 제한된 보조색.
- 로고 탐색: 펼친 책의 틈이 작은 서식지 문으로 이어지는 형태. 전승권 중 하나의 종교 상징을 전체 브랜드 로고로 쓰지 않는다.
- 환수: 고유 실루엣, 2~3개 주요 색, 작은 크기에서도 보이는 대표 동작. 픽셀 아트는 후보이며 비용·가독성 시제품으로 결정.
- 도감: 따뜻한 현장 관찰 노트. 복잡한 고문서 글꼴보다 읽기 쉬운 본문.
- 금지할 혼동: 특정 수집 게임의 알·볼·도감 배치·진화 연출·효과음을 함께 모방하는 것.
