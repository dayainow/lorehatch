# Lorehatch · 로어해치

> 전설이 쉬어 가는 작은 보호구역.
> A little sanctuary for living legends.

**2026-10-26 · 기획 v0.1 · 작업명 / 개발 전**

작업하거나 공부하는 동안 세계의 전승에서 영감을 받은 작은 환수를 만나고, 돌보고, 관찰 도감을 완성하는 데스크톱 동료 제품입니다. 북유럽과 이집트 신화를 하나의 역사로 합치지 않고, 각 전승의 독립된 서식지를 오가는 보호구역으로 연결합니다.

이 저장소에는 기획 문서와 초기 콘텐츠 데이터만 있습니다. 실행 가능한 앱, 완성 아트, 검증된 구매 수요는 아직 없습니다. 이름은 제한적인 웹 검색을 거친 추천 작업명이며 상표·도메인·스토어 등록 가능성을 확인한 것은 아닙니다.

## 이번 기획의 결정

- 중심 경험: 수집 경쟁보다 **발견 → 돌봄 → 관찰 → 서식지 확장**.
- 첫 전승권: 북유럽의 가지숲 / 이집트의 새벽 습지.
- 플레이어: 포획자가 아닌 보호구역의 기록자.
- 캐릭터: 신화 속 존재 그 자체를 소유하는 대신, 전승에서 태어난 작은 **메아리 환수**라는 창작적 해석.
- 도감: 원전 설명 / 게임 창작 / 개체 관찰을 분리.
- 첫 검증판: 3종. MVP 목표: 6종 × 어린 모습·성장 모습, 총 12개 형태. 성장형을 별도 종으로 세지 않음.
- 우선 플랫폼: macOS 데스크톱. React 기반 공통 UI + Tauri 호스트는 검증할 기술 후보.
- Chrome 확장은 후속 검토. 첫 버전은 집중 타이머로 독립 동작하며 AI 로그·브라우징 기록을 수집하지 않음.
- 공개 서비스나 결제는 이번 작업에 포함되지 않음.

라이선스는 아직 선정하지 않았습니다. 공개 저장소 전환이나 다운로드 허용만으로 문서·코드·캐릭터의 자유 이용을 허용하지 않습니다. 외부 게임 자산·박물관 이미지·현대 번역문은 포함하지 않았습니다.
