# 도트 제작 규격·에셋 목록

## 확정 방향 / 검증할 규격

사용자가 선호한 방향은 도트풍이다. **32×32**는 제작 제안으로, 가독성 테스트 전 규격 확정이 아니다. 초기 기준: 투명 RGBA, 종별 8색 목표(외곽선 포함·투명 제외), 안티앨리어싱 없음, 한 방향. 2×/3× 정수 확대, nearest-neighbor.

그림 전체를 고해상도에서 축소만 해서는 픽셀 군집과 팔레트가 정리되지 않는다. 시안에 적힌 32×32는 실제 파일 규격이 아니다. 최종 스프라이트는 격자별 수작업 검수 필요.

## 3종 14프레임의 범위

- 공통 알: 2프레임. 색/문양은 추후 팔레트 또는 정적 오버레이로 구별. 오버레이를 만들면 별도 제작량으로 기록.
- 숲용: 아기 2 + 성장 2.
- 날개말: 아기 2 + 성장 2.
- 세머리 강아지: 아기 2 + 성장 2.
- 배경 1장, 기본 소품 3개, 메뉴바 아이콘, UI 심볼, 부화 효과음은 **별도**.

8색 제한으로 세 머리가 읽히지 않으면 머리 위치와 명암부터 수정. 형태별 그림 크기를 달리 키우기 전에 같은 규격에서 비교한다.

## 애니메이션 예산

기본 대기: 두 프레임을 약 600ms 간격으로 시작해 테스트. 프레임당 한두 부분만 움직이고 발 기준선 고정. 걷기 애니메이션 대신 위치 보간 이동, 클릭 반응은 짧은 상하 이동, 좌우 방향은 반전. 반전하면 의미가 달라지는 문양/문자는 쓰지 않는다.

잠자기는 초기에는 멈춤 상태와 UI 표시로 처리. 눈 감은 별도 그림을 넣으면 프레임 수 추가. 부화는 공통 알 흔들림·작은 파편 오버레이·아기 등장으로 구성하고 전용 종별 부화 애니메이션은 없음. 모션 감소 설정에서 흔들림·점프·보간을 끈다.

## 납품 규격 후보

`<species-id>-young-idle.png`, `<species-id>-companion-idle.png`: 32×32 프레임 두 개를 가로로 붙인 64×32 PNG. 알도 동일. 파일명에 `@2x` 없이 원본을 보관하고 표시 배율은 코드가 처리.

manifest에 cell size, frame count, fps/duration, 발 기준점, 방향, 팔레트, 원본 경로, 제작자/권리 기록. Aseprite 등 편집 원본 형식은 제작 도구 선정 후 확정. 자동 도구를 사용해도 원본/검수 기록을 남긴다.

## 시안의 출처와 한계

[도트 방향 v1](../assets/concepts/pixel-direction-v1.png)은 내장 이미지 생성 도구로 만든 스타일 탐색 이미지이며 사용자가 선호했다. 원본 생성물은 `exec-ec62e5c9-6daa-4c2a-84b2-9b4c4e7196b4.png`이다. 사용자가 첨부한 게임 캐릭터 이미지는 작은 도트 크기감 참고로 제공됐으며 그 파일 자체는 저장소에 포함하지 않았다. 시안은 출시용 아트나 픽셀 규격 검증 결과가 아니다.

재생성용 요구 요약: 독자적인 숲용/날개말/세머리 강아지 3종, 같은 작은 도트 규격, 제한 팔레트와 또렷한 실루엣, 정확히 한 몸·세 머리의 강아지, 말의 뿔 없음. 기존 프랜차이즈 캐릭터의 외형·팔레트·포즈를 복제하지 않음.

## QA

실제 원본 픽셀 크기·색상 수·알파·부분 투명 픽셀·시트 크기 검사, 확대 시 흐림 없음, 두 프레임 기준선 일치, 알/성장형과 팔레트 일관성, 머리·다리 수, 밝고 어두운 배경 대비. 생성 이미지의 글자를 스프라이트에 포함하지 않음.
