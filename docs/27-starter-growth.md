# 시작 친구의 성장

현재 구현은 알 → 아기 → 성장의 흐름이며, 부화 후 모습이 바뀌는 성장은 한 번이다. 이름과 종 ID는 유지한다. 3단계 진화나 진화 분기는 아직 없다.

2026-11-05 시작 3종의 32×32 스프라이트를 다시 작성했다.

- 모루잎 / 풀 — 씨앗 얼굴·접힌 잎귀·덩굴 꼬리. 성장하면 넓은 잎날개와 머리의 새싹이 드러난다.
- 포루 / 물 — 둥근 아기 말·물방울 앞머리·작은 물결 날개. 성장하면 날개가 크게 펴지고 물빛 꼬리가 자란다.
- 코코두 / 불 — 한 얼굴의 아기 강아지, 숯빛 귀와 작은 불씨 꼬리. 성장하면 포근한 불꽃 목털과 길어진 불씨 꼬리가 생긴다.

캐릭터 선택에서 서로 다른 성격과 실루엣이 읽히도록 자체 제작했다. 다른 게임의 캐릭터·스프라이트를 사용하지 않았다. 비교 그림은 media/starter-growth.svg이며 실제 게임 SVG에서 생성한다.

불 스타터의 이전 케르베로스 디자인은 사용자 요청으로 교체했다. G02 ID와 코코두 이름은 유지해 소유·성장·돌봄·추억·관계 진행이 이어진다. S09 전승 자료는 역사적 기록에만 남기며 현재 캐릭터의 출처로 표시하지 않는다.
