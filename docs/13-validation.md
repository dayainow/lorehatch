# 검증 기록

2026-10-29 · 브라우저 알파 v0.5

## 자동 검증

`npm test`로 21개 테스트 통과. 3종 전체 성장, 일반/체험 저장 분리, 첫 부화 1회, 중복 지급 방지, 초과 시간 이월, 날짜 역행 시 상한 유지, 잘못된 수치/파일 차단, 파트너와 육성 대상 분리, 원본 손상/누락 시 백업 복원, 백업·원본 쓰기 실패 시 진행 보존을 확인했다. 공유 주소에서 쿼리·해시가 제거되는 것도 확인했다.

`npm run check`는 모듈 문법과 밸런스 데이터 일치를 확인한다. `npm run build`는 정적 결과물을 생성한다. 테스트의 저장 오류는 메모리 저장소에 주입한 오류다.

## 브라우저 확인

- 첫 방문 안내와 이용 안내 다이얼로그 표시 확인.
- 공유 다이얼로그, 별명·집중 시간을 제외한 카드 다운로드 확인.
- GitHub Star 링크의 목적지가 dayainow/lorehatch임을 확인. 공개 전환 후 로그인 없이 저장소 HTTP 200을 확인.
- 1440px 데스크톱과 작은 화면 레이아웃 확인. 실제 캡처는 docs/screenshots/에 보관.
- 별도 테스트 origin에서 첫 알 선택 → 즉시 부화 → 30초 성장 → 성장 확인 → 새로고침 후 성장 상태 복원을 확인. 콘솔 오류·경고는 확인 시점에 없었다.

이전 브라우저의 성장 완료 펫 복원은 사용자 전달 결과다. 기존 저장을 초기화하지 않았다.

- 빌드된 dist를 로컬 `/lorehatch/` 경로에서 제공해 첫 화면, 이미지 로드, 일반/체험 모드 이동을 확인. 공개 Pages 서버 자체를 검증한 것은 아니다.
- GitHub PR #1의 push/PR CI 검증이 모두 통과했다.

## 공개 배포 검증

- 기존 미커밋 PWA/macOS 구현을 포함한 작업 트리에서 Node 테스트 26개, `npm run check`, 정적 빌드 통과.
- `npm run package:web` 실행: ZIP 최상단 index.html과 필수 런타임 파일 존재, unzip 무결성 검사 통과. SHA-256 파일 생성. itch.io 업로드는 하지 않음.
- 실제 Chrome, `http://127.0.0.1:4183/?mode=demo`, dist 빌드: 모루잎 선택 → 즉시 부화 확인 → 집중 시작 → 30초 성장 준비 → 성장 확인 → 도감 1/3 및 성장 단계 → 새로고침 뒤 성장 펫 유지 확인.
- `docs/screenshots/v06-*.jpg` 4장은 위 실제 체험 화면이다. 전체 3종 수집 또는 고객 사용 기록을 연출한 이미지가 아니다.
- 공개 Pages의 app/main.mjs를 읽어 v0.5.1 표시 확인. GitHub Releases 조회 결과 목록 비어 있음. 로컬 v0.6은 공개 배포하지 않음.
- 미검증: 실제 오프라인 재실행/업데이트, 모바일 브라우저 설치, itch.io iframe, macOS GUI·서명·공증, 고객 재미/반복 사용. 기존 단위 테스트 통과로 이를 대체하지 않는다.

### 같은 날 후속 검증: 오프라인과 업데이트

- 로컬 서버 `127.0.0.1:4183` 연결 실패를 curl로 확인한 상태에서 Chrome 새 탭으로 체험 정원 열기 및 새로고침 성공. 기존 성장한 모루잎과 도감 1/3 유지. `v06-offline.jpg` 기록.
- 서버를 최신 dist로 다시 시작한 뒤 새 버전 배너 확인 → 업데이트 버튼 클릭 → 재로딩 후 성장한 모루잎과 도감 1/3 유지. 네트워크 전체 차단이 아니라 해당 앱 서버 중단 상황의 검증이다.
- macOS iconutil은 샌드박스 안에서 Invalid Iconset 실패, 동일 입력의 정상 macOS 실행에서는 성공. 아이콘 PNG 정규화 추가와 별개로 실행 환경 제한을 구분해야 한다.

### macOS 설치 파일 생성 결과

- `npm run package:mac` 정상 macOS 도구 환경에서 통과. arm64 + x86_64 universal, 최소 macOS 13.0, ad-hoc codesign strict 검증 및 ZIP 무결성 검사 통과.
- 네이티브 실행 파일의 `--self-test`: 원자적 저장, 재시작 로드, 손상 시 백업 복구, 허용 키 격리 통과.
- 설치 파일: `release/Lorehatch-0.6.0-macOS-universal.zip`. SHA-256: `7f951a8cf1fc2c719c21f23d7ba4dd157ecb05f84e435b1d160bc6837fa29d3d`.
- `LOREHATCH_DATA_DIR=.../work/native-qa`로 기존 사용자 저장과 분리해 실행. 프로세스 실행은 확인했으나 `cua.getApp`이 약 14분 후 시간 초과되어 실제 창 상호작용·부화·파일 내보내기·재실행 GUI 검증은 완료하지 못했다. 프로세스 실행과 self-test를 GUI 검증으로 간주하지 않는다.
- Swift module cache를 패키징 정리 대상 밖의 `build/swift-cache`에 두어 재빌드 시 캐시 유지. PNG를 sips로 정규화하되 샌드박스 iconutil 실패는 별도 실행 환경 문제로 기록.
- 공개 게시·Developer ID 서명·공증은 수행하지 않았다.

### 숲 표지 디자인 후속 검증

Mac 첫 실행에서 토큰 루트 URL의 마지막 슬래시가 생략되면 탐색이 취소되는 문제를 수정했다. 새 universal ZIP의 실제 창에서 세 친구와 첫 알 버튼을 확인하고 포루를 골라 부화시켰다. 아기 도감 등록 안내를 확인했다. 표지 캡처는 forest-cover.jpg에 보관했다. 웹 ZIP 무결성과 26개 테스트가 통과했다. macOS 공증, 모바일 실기기, 실제 스토어 임베드 검증은 남아 있다.
