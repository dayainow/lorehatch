# 사업·벤치마크·검증

## 포지셔닝

‘일하면서 모으는 전설의 작은 동료’라는 약속. 유명 캐릭터 인지도를 빌리지 않고 전승 소재의 친숙함과 독자적인 아트·애니메이션으로 첫 관심을 얻는다. 실제 고객 확보 비용과 구매 의향은 미검증이다.

## 벤치마크 — 공식 설명 조사, 직접 플레이 전

- Whimside: 배경에서 조용히 실행되는 생물 수집·번식·꾸미기. 배울 것: 작은 화면의 수집 재미, 다음 지역을 여는 흐름. 우리의 차별화 가설: 전승의 출처가 있는 관찰 도감과 예측 가능한 발견 과제. https://whimside.com/faq/
- Spirit City: Lofi Sessions: 집중 도구와 정령 발견·공간 꾸미기. 배울 것: 집중을 방해하지 않는 보상. 우리의 차별화 가설: 작은 동료 창과 여러 문화권의 보호구역. https://mooncubegames.com/home/spirit-city-lofi-sessions-press-kit/
- Weyrdlets: 데스크톱 반려 생물. 배울 것: 짧은 동작의 애착, 창 배치와 방해 정도. https://store.steampowered.com/app/2366060/Weyrdlets__Idle_Desktop_Pets/
- PokeTokenBar: 기존 AI 작업량을 수집·성장에 연결. 배울 것: 별도 일을 시키지 않는 보상. 우리는 유명 IP나 토큰 소모를 필수 조건으로 삼지 않음. https://github.com/chattymin/PokeTokenBar

공식 설명은 매출·유지율·사용성의 증거가 아니다. 다음 단계에서 첫 보상 시간, 하루 클릭 수, 방해 빈도, 수집 페이지 읽기, 중복 처리, 결제 구성 등을 직접 기록한다. 유료 게임 구매는 이번 작업에서 수행하지 않았다.

## 홍보 가설

### 후킹 장면

작업을 마친 화면 옆으로 작은 다람쥐가 편지를 가져온다. 편지에 ‘새벽 습지에서 새로운 흔적을 찾았습니다’. 펼치면 작은 베누 메아리가 첫 발을 내딛는다. 문구: **오늘의 작업 끝에, 새로운 전설 하나.**

두 번째 장면은 ‘내가 함께한 환수’ 카드. 실제 문서명, 코드, 사용 비용을 자동 포함하지 않는다. 카드에 종·서식지·발견한 행동만 표시한다.

### 최초 채널

생산성/데스크톱 꾸미기/코지게임 관심층에 서로 다른 메시지를 테스트한다. 처음부터 전 세계를 대상으로 광고비를 쓰지 않는다. 작가와 3종 아트 협업을 검토하고 공동 홍보 권한·일정을 계약에 포함할 수 있는지 확인한다. 권한 없이 커뮤니티 홍보 글이나 작가 연락은 발송하지 않는다.

## 검증 순서와 내부 기준

아래는 업계 평균이 아닌 제안된 작은 표본의 중단/수정 기준이다.

1. 이름/실루엣 인터뷰 5~8명: 이름 듣고 검색어 재현, 3종 구분, 가장 데려오고 싶은 생물 선택. 혼동이 반복되면 수정.
2. 15초 영상 3안: 동일 조건에서 보여주고 ‘무슨 제품인지’ 설명하게 한다. 귀엽다는 반응과 실제 설치 의향을 구분한다.
3. 15~20명, 7일 로컬 테스트: 첫 환수까지 완료 비율, 두 번째 만남 비율, 7일차 재실행, 동료 숨기기 이유, 공유 행동을 동의하에 측정. 핵심 실패는 설치 후 첫 만남을 못 하거나 업무 방해로 끄는 것.
4. 가격 조사: 구매 의향 인터뷰와 실제 결제를 구분. 유료 전환률은 결제 실험 전까지 주장하지 않는다.

판단 예: 테스터 20명 중 10명도 자발적으로 둘째 날 다시 켜지 않는다면 콘텐츠 수 확장보다 반복 흐름을 먼저 수정. 이 수치는 작은 표본의 팀 의사결정용 가정이다.

## 수익화 후보

먼저 무료 체험 3종으로 반복 사용을 검증하고, 기본판 일회성 구매 + 전승권 확장팩을 후보로 시험한다. 한국 가격 인터뷰 후보: 기본판 9,900/14,900/19,900원. 확장팩 가격은 기본판 구매 이유와 아트 제작비를 확인한 뒤 설계. 가격 확정·판매 개시 아님.

구독은 지속적 콘텐츠·서비스 가치를 입증하기 전에는 도입하지 않는다. 확장팩은 포함 생물 수와 내용을 공개하고 유료 확률형 뽑기를 쓰지 않는다. 구매하지 않아도 기존 환수가 사라지거나 아프지 않는다.

## 비용과 손익 계산

주요 비용: 오리지널 아트/애니메이션, 앱 개발·QA, 신화 조사/감수, 사운드 권리, 서명·배포·고객 지원, 선택적 마케팅.

단위 공헌이익 = 세금·환불 조정 후 판매 수입 - 해당 채널 수수료 - 판매당 변동비 - 계약상 로열티(있을 때).
손익분기 판매 수 = 회수할 고정비 / 양의 단위 공헌이익.

현재 견적·판매 데이터가 없어 판매량이나 수익을 예측하지 않는다. 제작비는 최소 3종 시제품 견적부터 받는다. 최소 팀에서도 6종×2형태×4상태는 48클립이며 프레임 수에 따라 비용이 크게 달라진다.

## 매각 가능성을 위한 자산 관리

브랜드·캐릭터 원본·애니메이션·코드·음원별 권리 기록을 남긴다. 외주 계약은 앱/마케팅 사용, 수정, 재배포, 후속 제작, 사업 양도 시 권리 승계를 명확히 한다. 구매자는 정리된 자산과 실제 고객 지표를 볼 수 있어야 한다. 특정 회사의 인수 의향은 확인되지 않았다.
