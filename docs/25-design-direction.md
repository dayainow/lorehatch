# 정원 화면 아트 디렉션

짙은 숲색 배경, 종이 같은 따뜻한 조작 영역, 크게 보이는 픽셀 캐릭터를 중심으로 구성한다. 정원 장면 → 성장 상태 → 돌봄·관계 → 도감 순서로 읽히도록 한다. 캐릭터 반응과 버튼의 작은 눌림을 강조하며 동작 줄이기를 따른다.

2026-11-04 적용: 정원과 육성 패널을 하나의 화면으로 연결하고 패널 간격·타이포·버튼·도감 표본·상세 창 재질을 정리했다. Mac 실제 화면에서 그림이 패널을 덮는 문제를 발견해 최소 폭과 종횡비 제약을 수정했다. 검증 이미지는 screenshots/v06-garden-redesign.jpg다.

출시급 품질에 필요한 후속 작업: 18종의 고유 대기·돌봄 애니메이션, 서식지별 별도 배경 원화, 영어 UI, 작은 화면과 키보드 탐색 검증, 새 사용자 플레이테스트. 현재 화면 개선만으로 유명 상용 게임 수준의 완성도가 검증되었다고 주장하지 않는다.
