# 기획 결정 기록

## v0.2 / 2026-10-27

사용자가 선호한 방향: 저비용 도트, 알 부화, 쉬운 이름, 판타지와 여러 전승의 도감.

- 고해상도 동화풍 → 작은 도트. 생성 시안은 스타일 참고, 최종 스프라이트 아님.
- 탐방/흔적/관찰 퀘스트 → 알/시간/성장/도감으로 단순화.
- 모든 환수는 전승의 알에서 탄생. 원전의 출생/번식 사실과 구분.
- 북유럽/이집트 2구역 → 드래곤/그리스/동아시아/북유럽/이집트 컬렉션 목표.
- 6종 MVP → 3종 MVP / 10종 첫 컬렉션. 기존 데이터 ID는 유지하며 N03/E03은 보류.
- 어려운 수식 이름 → 숲용·날개말·세머리 강아지 등 쉬운 종 이름.
- 작업명 환수정원 추가. 영문/저장소 Lorehatch 유지. 상표 확정 아님.
- 48클립 초기 제작안 → 14 기본 프레임 목표. UI/배경/별도 효과는 제외한 수량임을 명시.

미검증: 실제 픽셀 규격, 성장 속도, 스택, 가격, 전승 상세 검수, 브랜드 사용 가능성, 사용성/성능/수익성. v0.1은 Git 이력에 남고 현재 문서는 v0.2를 기준으로 사용한다.

## v0.3 / 2026-10-27 — 익숙한 용어로 변경

사용자 요청에 따라 포켓몬 공식 안내와 다마고치 공식 설명서의 직접적인 기능 명명 방식을 참고했다. ‘전승의 알’은 ‘알’, ‘온기’는 별도 재화 없이 ‘집중 시간’, ‘메아리 환수’는 ‘펫’, ‘함께하기 시작’은 ‘집중 시작’으로 변경. 페가수스·케르베로스는 원래 이름을 쓰고 쉬운 설명을 병기한다. 위 v0.2 기록은 과거 결정이며 현재 용어 기준은 docs/11-language.md다. 성장 속도와 기능 범위는 유지한다.
