# 첫 도감 10종

## 범위

MVP는 숲용·페가수스·케르베로스 3종이다. 아래 10종은 이후 첫 컬렉션의 기획 목표이며 모두 구현되거나 아트가 완성된 상태가 아니다. 각 종에는 아기/성장 모습이 있다. 수집 수는 종 수로 계산한다.

## D01 숲용 — 오리지널 / MVP

잎무늬 알 → 짧은 잎날개와 도토리뿔의 아기 → 넓은 잎날개와 가지뿔의 성장 모습.
느긋하고 낮잠을 좋아한다. 대기 때 눈을 깜빡이고 등 위 잎이 한 칸 들썩인다. 문구: **작은 날개 아래, 당신만의 숲이 자랍니다.**
초록·크림·갈색의 큰 면으로 구분. 성장형은 단순 확대가 아닌 날개와 뿔의 변화. 특정 전승의 실제 종이 아닌 창작.

## G01 페가수스 — 날개 달린 말 / MVP

깃무늬 알 → 작은 날개의 아기 말 → 넓은 깃날개와 긴 갈기의 성장 모습.
호기심 많고 착지가 서툴다. 문구: **오늘은 어제보다 조금 높이 날았습니다.**
상아색 몸·푸른 갈기·짧은 발굽. 유니콘 뿔 없음. 말의 주둥이, 네 다리, 두 날개가 식별돼야 한다. 전승 근거 S08; 알·아기·성장은 창작.

## G02 케르베로스 — 세 머리 강아지 / MVP

세점 알 → 처음부터 세 머리인 아기 → 갈기와 몸이 풍성해진 성장 모습.
한 머리는 잠꾸러기, 하나는 호기심, 하나는 먹보. 문구: **셋이 함께 지키면, 낮잠도 든든합니다.**
갈색 한 몸·세 머리·네 다리·한 꼬리. 머리 하나씩 따로 움직이는 리깅은 MVP 제외. 가독성이 가장 어려운 종이므로 32px에서 구분되지 않으면 세부를 줄이고, 실패 시 전체 규격을 48px로 재검토. 전승 근거 S09.

## D02 불꽃용 — 오리지널 / 후속

불꽃무늬 알 → 작은 꼬리 불씨 → 넓어진 날개와 큰 불빛. 용감한 척하지만 자기 재채기에 놀람. 숲용의 팔레트 변경만으로 만들지 않고 뿔·날개·꼬리 실루엣을 다르게 설계.

## A01 구미호 — 한국 설화 모티프 / 후속·조사 전

달무늬 알 → 아홉 작은 꼬리를 모은 아기 → 부채처럼 펼친 아홉 꼬리. 조용하지만 친해지면 장난을 침. 꼬리 수의 성장 전설을 임의로 주장하지 않음. 32px에 아홉 꼬리 표현이 어려우면 정적 도감 확대에서 구분하고 작은 스프라이트는 실루엣으로 표현하는 방법을 검증. 출처 조사 게이트.

## A02 해태 — 한국 전승 모티프 / 후속·조사 전

돌결 알 → 둥근 몸과 작은 뿔 → 넓은 앞발과 구름갈기. 흐트러진 소품을 정돈하는 성격은 창작. 형상과 지역 차이 출처 확인 후 확정.

## N01 전령 다람쥐 — 라타토스크 / 후속

잎맥 알 → 큰 꼬리와 작은 주머니 → 길어진 꼬리와 풍성한 주머니. 도토리를 꺼내다 편지를 떨어뜨리는 성격. 전승 근거 S01. 우편·주머니 디자인은 창작이며 탐방 기능을 뜻하지 않음.

## N02 여덟발 말 — 슬레이프니르 / 후속

여덟줄 알 → 짧고 둥근 여덟 다리 → 길어진 갈기와 안정된 자세. 전승 근거 S01. 다리가 많은 구조는 제작 위험이므로 첫 MVP에서 제외. 런타임 다리별 애니메이션 없이 정적 도트에서 판독 가능한지 먼저 검증.

## E01 새벽새 — 베누 / 후속

물빛 알 → 짧은 다리와 작은 머리깃 → 길어진 목과 두 갈래 깃. 물에 비친 자신에게 인사하는 행동은 창작. S02·S03. 현실 새벽 접속 조건을 두지 않음.

## E02 태양 딱정벌레 — 스카라브 모티프 / 후속

빛점 알 → 작은 구슬을 미는 아기 → 넓은 등판의 성장 모습. 끈기 있지만 구슬에서 미끄러지는 성격. S04·S05. 케프리 신 자체를 소유하는 설정 아님.

## 보류 목록

기존 ID N03 뿌리용, E03 스핑크스는 데이터에서 삭제하지 않고 보류로 남긴다. 초기 10종 수에 포함하지 않는다. 이유: 기본 용과의 차별화 및 원전 검토, 얼굴/형상의 도트 가독성.

## 실제 도감 페이지 예시

**페가수스** / 페가수스 모티프 / 아기·성장 두 모습

“오늘은 어제보다 조금 높이 날았습니다.”
성격: 호기심 많음. 좋아하는 것: 바람, 넓은 풀밭. 사용자 기록: 별명·만난 날·성장한 날. 다음 목표: 함께한 시간으로 성장.

접힌 ‘전승 이야기’에서 날개 달린 말 모티프와 출처를 확인. ‘우리의 설정’에는 파란 갈기·성격·알을 명시. 실제 구현 전에는 가짜 사용자 날짜나 완료율을 사실처럼 표시하지 않는다.
