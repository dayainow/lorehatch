18종 뒤에 새 ID를 추가했다. 아기와 성장 모습은 같은 종이며 총 30종·60가지 모습·120개 캐릭터 프레임이다. 알 프레임 2개는 별도다. 전승 자료를 가져오지 않은 자체 창작이다.

새 친구마다 성격, 선호, 아기·성장 돌봄 반응, 선택형 만남, 추억 카드, 상호 관계를 연결했다. 총 추억 카드 30장, 친구 이야기 15편, 달성 목표 12개다. 성장 시간과 하루 적립 한도는 변경하지 않았다.
