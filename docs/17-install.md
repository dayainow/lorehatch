# 설치·업데이트·진행 복구

2026-11-02 · 로컬 v0.6.0 기준. 공개 Pages와 GitHub Releases에 이 버전이 배포됐다는 뜻은 아니다.

## 웹에서 플레이

[공개 브라우저 알파](https://dayainow.github.io/lorehatch/)를 열거나 로컬에서 `npm run dev`를 실행한다. 첫 알은 즉시 부화하며, 집중 시작을 눌러야 성장 시간이 쌓인다. 정원 화면을 벗어나거나 잠자기 상태가 되면 적립이 멈춘다.

## PWA로 설치

v0.6 빌드를 HTTPS 또는 localhost에서 연다. Chrome·Edge의 설치 메뉴, 지원되는 Mac Safari의 Dock에 추가, iOS Safari의 홈 화면에 추가를 사용한다. 메뉴·지원 여부는 브라우저에 따라 다르다. 앱 설치가 Chrome 웹스토어 등록을 의미하지 않는다.

오프라인용 로컬 확인:

```sh
npm run build
SERVE_DIST=1 npm run dev
```

온라인으로 첫 화면과 서비스 워커 설치를 완료한 뒤 연결을 끊고 재실행한다. 개발 서버 원본의 서비스 워커에는 빌드 시 생성하는 사전 캐시 목록이 없으므로 오프라인 검증에는 `dist`를 사용한다. 새 버전 안내가 나타나면 진행을 저장한 뒤 업데이트한다. 2026-11-02 Chrome에서 앱 서버 중지 후 새로고침과 재연결 후 업데이트 버튼 적용, 기존 펫 유지까지 확인했다. 다른 브라우저의 설치형 실행은 별도 확인 항목이다.

## macOS 앱

2026-11-02 GitHub Releases 조회 결과 공개 릴리스가 없다. 앱 패키징 코드는 있으나 다운로드 가능한 정식 앱으로 안내하지 않는다.

2026-11-02 로컬 `release/Lorehatch-0.6.0-macOS-universal.zip`을 생성했고 arm64/x86_64 포함, ad-hoc 서명 검증, ZIP 무결성 및 네이티브 저장 자가 테스트를 통과했다. 실제 창 조작은 도구 시간 초과로 미검증이다. [Mac 5분 확인 순서](20-store-publishing.md)를 따른다.

Mac과 Xcode Command Line Tools가 있는 개발 환경에서 `npm run package:mac`을 실행하면 `release/`에 ZIP을 만든다. 현재 스크립트는 ad-hoc 서명만 사용한다. Developer ID 서명·공증 및 사용자 설치 검증 전이며 일반 배포 준비 완료를 뜻하지 않는다. 보안 기능을 끄는 방식으로 설치를 안내하지 않는다.

## 정원을 옮기거나 복구하기

1. 기존 정원에서 설정 → 파일 내보내기를 누른다.
2. 새 브라우저·앱에서 동일한 일반/체험 모드를 연다.
3. 설정 → 파일 가져오기에서 저장한 JSON을 선택한다.
4. 펫 종류·성장 단계·파트너가 일치하는지 확인한 뒤 기존 데이터를 정리한다.

브라우저·기기·주소가 다르면 별도 저장이다. Pages에서 itch.io로 옮겨도 자동 이전되지 않는다. 저장 실패가 뜨면 초기화하지 말고 기존 파일을 보관한다. 별명과 저장 파일은 공개 이슈에 올리지 않는다.
