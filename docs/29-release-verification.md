## 분리된 Mac GUI 재현

먼저 `npm run package:mac`으로 앱을 빌드한다. 다음 명령은 사용자 저장을 건드리지 않고 build/qa/run-* 아래 별도 앱과 저장 파일을 만든다.

```sh
node scripts/qa/prepare-mac.mjs C01
```

C01–C06 또는 F01–F06을 지정할 수 있다. 해당 종 직전까지 성장한 테스트 정원과 부화 준비된 알, 성장용 적립 시간을 준비한다. 출력된 MoamonQA.app을 열어 부화 → 성장 확인 → 돌봄 → 추억 선택 → 재실행 저장 유지를 확인한다. 미리 적립한 시간으로 진행하므로 실제 시간 적립·백그라운드 동작 검증은 아니다. 테스트 전용 앱을 일반 설치본 대신 배포하지 않는다.

첫 테스트 앱 실행은 자동 승인 검토의 사용량 제한으로 실행되지 않았다. 따라서 별도 저장 경로가 실제 실행 앱에서 적용되는지부터 확인해야 한다. 우회 실행은 하지 않았다.
