# v0.4 로컬 시제품 · 2026-10-29

## 이번 버전의 결정

첫 화면은 펫이 살 공간을 먼저 보여준다. 종이색 UI와 깊은 녹색 숲을 사용하고, 오른쪽에는 지금 키우는 대상과 집중 버튼만 둔다. 주요 동작은 알 흔들림, 두 프레임 대기, 쓰다듬기 반응, 부화·성장 등장이다. 동작 줄이기와 OS 동작 감소 설정을 따른다.

앱 검증을 빠르게 하기 위해 의존성 없는 ES 모듈/HTML/CSS로 구현했다. React/TypeScript/Tauri는 기존 기술 후보이며 이번 코드가 그 구현인 것은 아니다. 순수 domain.mjs와 storage.mjs를 분리해 네이티브 호스트로 옮길 경계를 남겼다.

## 플레이 가능한 범위

- 첫 알 즉시 부화, 이후 25분 부화 / 75분 성장 / 하루 150분 상한.
- 체험 모드: 15초 부화 / 30초 성장, 일반 모드와 별도 저장.
- 모루잎(숲용), 포루(날개말), 코코두(세 머리 강아지) 3종. 이름은 창작 후보이며 확정 브랜드/IP가 아니다. 이전 모그리 후보는 채택하지 않았다.
- 32×32 SVG 픽셀 좌표로 직접 제작한 아기/성장 대기 12프레임과 알 2프레임. 기존 콘셉트 이미지는 별도 참고 자료다.
- 알 선택, 부화, 성장 확인, 다음 알, 도감, 아기/성장 보기, 별명, 파트너 선택.
- 들꽃/버섯/조약돌 소품 선택, 작은 화면 모드, 쓰다듬기 반응.
- localStorage 저장, 마지막 정상 백업, JSON 내보내기/가져오기, 모드별 초기화.

## 브라우저 시제품의 시간 정책

화면이 보일 때 사용자가 시작한 시간만 누적한다. 다른 탭/앱 전환으로 페이지가 숨겨지면 멈춘다. 5초보다 긴 tick 공백도 중지한다. 완성 임계값에서 세션은 멈추고 확인을 기다린다. 그 tick의 초과 시간은 다음 대상으로 이월한다. 5초 체크포인트와 주요 상태 전환 때 저장한다. 종료 후 오프라인 보상은 없다.

네이티브 제품에서는 다른 앱으로 작업하는 동안에도 집중이 이어져야 한다. 이 브라우저의 visibility 정책을 그대로 이식하지 않는다. 네이티브 단일 타이머 + OS 수면/깨우기 이벤트 검증이 다음 단계의 선행 조건이다.

하루 버킷은 로컬 날짜가 앞으로 갈 때만 갱신한다. 과거 날짜로 돌아가도 상한을 다시 열지 않는다. 시간 조작을 막는 DRM은 아니며, 실제 자정 경계의 250ms tick 분할 정산은 아직 구현하지 않았다.

## 저장과 실패 처리

Web Locks로 같은 모드의 쓰기 탭을 하나만 허용한다. 두 번째 탭은 읽기 전용이며 첫 탭 종료 후 새로고침한다. 잠금 미지원 환경은 안전하게 읽기 전용으로 연다. 가져오기는 100KB/버전/ID/중복/단계/날짜/수치/닉네임을 검사하고 알려진 필드만 채택한다. 일반/체험 파일 교차 가져오기를 막는다. 잘못된 파일은 기존 진행을 바꾸지 않는다.

localStorage는 브라우저 데이터 삭제에 함께 사라진다. 파일 내보내기로 보관한다. 원자적 파일 교체와 macOS 앱 데이터 경로는 미구현이다. 실제 디스크 용량 부족, 브라우저 프로세스 강제 종료, macOS 수면/깨우기는 별도의 기기 검증이 필요하다.

## 2026-10-29 재검증과 저장 보강

기존 자동 테스트 15개를 다시 실행해 모두 통과했다. 원본 저장이 없거나 빈 문자열일 때 정상 백업을 복원하도록 보강했다. 백업까지 손상되면 두 원본을 보존하고 복구 안내를 표시한다. 정상 원본을 백업하는 쓰기가 실패하면 원본 교체를 중단한다.

회귀 테스트 5개를 추가해 총 20개가 통과했다. 원본 누락/빈 값, 백업 손상, 백업 쓰기 실패, 원본 쓰기 실패, 복구 후 재저장을 검증했다. 쓰기 실패는 메모리 저장소에서 주입한 오류이며 실제 디스크 부족 검증은 아니다. `npm run check`와 `npm run build`도 통과했다.

이전 브라우저에서 성장 완료 펫이 정상 복원됐다는 결과는 사용자 전달 사항이다. 이번 재검증에서는 해당 브라우저 저장을 직접 열거나 변경하지 않았다. 네이티브 호스트와 실제 수면 복귀 검증은 남아 있다.

## 다음 구현 순서와 완료 기준

1. 네이티브 호스트 기술 검증: 메뉴바 창, 투명 동료 창, 드래그, 전체화면에서 숨김/표시. 완료 기준은 다른 앱에서 일하며 타이머가 지속되고 수면 동안은 적립되지 않는 것.
2. 저장 어댑터: 앱 데이터 경로의 JSON + 정상 백업 + 원자 교체. 종료/강제 종료/손상/재시작에서 진행 보존 검증.
3. 사용성 알파: 3명이 도움 없이 첫 부화→집중 시작→성장 확인. 혼동 지점과 재방문 의향을 직접 기록. 실제 사용 데이터 없이 재미·생산성 향상을 주장하지 않는다.
4. 캐릭터 정제: 후보 이름 선행 검색, 실루엣 구분, 2배/3배 크기 가독성, 모션 정리. 10종 확장은 3종 경험을 검증한 뒤 진행한다.
5. 배포 준비: 서명·공증·설치·업데이트·제거 검증. 결제·계정·분석·공개 배포는 현재 범위 밖.

## 로컬 실행

Node.js 22 이상. 외부 패키지 설치는 필요 없다.

```sh
cd /Users/softday/Documents/source/lorehatch
npm run dev
```

일반: http://127.0.0.1:4173/ · 빠른 체험: http://127.0.0.1:4173/?mode=demo

서버 중지: 실행 터미널에서 Ctrl+C. 포트 충돌 시 `PORT=4174 npm run dev`를 사용하되 저장은 origin(포트)별로 나뉜다.

```sh
npm test
npm run check
npm run build
```

빌드 결과는 dist/. 파일 더블클릭이 아닌 HTTP 서버로 열어야 한다.
