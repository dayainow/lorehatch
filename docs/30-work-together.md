# 같이 작업하기와 빠른 성장

2026-11-06. 사용자 피드백에 따라 일반 부화 25→5분, 성장 75→15분으로 조정했다. 첫 알 즉시 부화와 하루 적립 한도 150분, 체험 15/30초는 유지한다. 수치는 검증된 최적값이 아닌 플레이테스트 가설이다.

‘집중 시작’을 ‘같이 작업하기’로 바꾸고 기본 세션은 시간제한 없는 ‘계속 함께’로 설정했다. 선택 시간은 5/15/30분이다. 남은 시간에 초를 표시하고 일시정지 중에는 시작해야 적립된다는 설명을 표시한다.

기존 저장에는 balanceVersion이 없다. 이전 25/75분 기준으로 먼저 검증한 뒤 새 목표를 넘은 진행은 확인 대기로 전환하고 남은 초를 적립함으로 옮긴다. 이미 기록된 총 시간과 일일 적립은 그대로 유지한다. 이전 적립함 최대 18000초도 보존한다. 새 저장은 balanceVersion:1로 구분한다.

자동 컴퓨터 사용 감지는 이번 변경에 포함하지 않았다. 수동 함께하기는 여전히 화면이 보일 때만 적립하며 잠자기·숨김에서 멈춘다. Claude Code 완료 훅은 선택적 실험 기능이며 실제 공급자 검증이 남아 있다. 이 문구 변경을 백그라운드 성장 구현으로 소개하지 않는다.
