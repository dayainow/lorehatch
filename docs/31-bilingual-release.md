# 0.7.0 영문·국문 웹 알파 출시 점검

점검일: 2026-11-11. 공개 대상은 웹 알파와 정적 사이트 압축 파일이다.

## 이번 변경

- README.md는 영어, README.ko.md는 한국어로 분리하고 각 언어의 실제 화면과 30종 도감을 사용했다.
- 게임의 메뉴·설정·30종 도감·돌봄·30개 만남·15개 관계·14개 수집 목표를 두 언어로 제공한다.
- 첫 실행은 브라우저/운영체제 언어를 따르며 명시적인 언어 링크가 우선한다. 화면 언어 변경은 저장된 종 ID와 개인 별명을 바꾸지 않는다.
- 맥 메뉴에도 언어 선택을 전달한다. 네이티브 화면 전체의 수동 검증은 미완료다.

## 확인한 범위

- 자동 테스트 45개 통과: 기존 성장·저장·수집 검사 및 전체 화면 번역 누락·별명 보존 검사.
- 정적 검사, 웹 빌드, 웹 ZIP 무결성 검사 통과.
- 맥 범용 빌드와 저장·재시작·백업 자체 검사, 임시 서명 검증 통과.
- 실제 브라우저: 영어 첫 부화, 작업 시작/정지, 돌봄, 추억 획득, 도감, 언어 전환 후 기록 보존.
- 별도 빠른 체험 저장에서 30초 성장 완료와 성장한 모습 공개 화면 확인.
- 좁은 화면과 데스크톱 폭 확인. 실제 두 언어 화면을 docs/screenshots/v07-garden-*.jpg에 저장.

## 출시 범위와 남은 일

웹 알파는 위 검증을 바탕으로 공개한다. 일반 사용자용 맥 설치판은 아직 출시하지 않는다.

1. 개발자 배포 서명과 애플 공증: 현재 기기에 유효한 코드 서명 인증서가 없다. 계정·인증서 준비가 필요하다.
2. 네이티브 플레이테스트: 실제 맥에서 메뉴바, 바탕화면 친구, 창 숨김·잠자기·재시작, 언어 전환, 백업 복구를 함께 확인해야 한다. 인텔 실기기 동작은 미확인이다.
3. 소규모 사용자 테스트: 설치·첫 부화·성장·재방문까지 실제 사용자 검증은 미실시다.

인공지능 완료 신호 연동은 실험 기능이다. 일반 기능으로 소개하려면 실제 공급자 세션 검증이 추가로 필요하다. 컴퓨터 사용량 기반 자동 성장, 120종 확장, 전투는 이번 출시 범위에 없다.

현재 수동 성장은 화면이 보이고 세션이 실행 중일 때만 쌓인다. 첫 부화는 즉시, 이후 부화는 5분, 성장은 15분이다. 이 제한은 두 README와 게임 안내에 공개한다.

빌드 성공은 배포 성공을 뜻하지 않는다. 공개 URL과 GitHub 릴리스는 게시 후 별도로 확인한다.
