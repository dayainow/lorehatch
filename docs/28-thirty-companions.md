# 30종 도감 확장 · 2026-11-05

18종 뒤에 새 ID를 추가했다. 아기와 성장 모습은 같은 종이며 총 30종·60가지 모습·120개 캐릭터 프레임이다. 알 프레임 2개는 별도다. 전승 자료를 가져오지 않은 자체 창작이다.

- 조개해변 C01–C06: 몽실(거품물개), 집게(산호게), 해초(해초해마), 말랑(조개문어), 반짝(모래별), 동글(야자오리).
- 꽃바람들판 F01–F06: 포근(민들레양), 두둥(빗방울코끼리), 토닥(온돌곰), 루루(꽃리본고양이), 윙윙(햇꿀벌), 보송(이슬친칠라).

각 서식지는 불·물·풀 두 종씩 구성한다. 18종을 성장시키면 해변, 24종을 성장시키면 들판이 열린다. 기존 ID·종 순서·소유·돌봄·추억 기록은 유지하며, 이전 18종 완성 저장은 다음 알을 고를 수 있도록 다시 열린다.

새 친구마다 성격, 선호, 아기·성장 돌봄 반응, 선택형 만남, 추억 카드, 상호 관계를 연결했다. 총 추억 카드 30장, 친구 이야기 15편, 달성 목표 12개다. 성장 시간과 하루 적립 한도는 변경하지 않았다.

검증: 자동 테스트 37개 통과. 전체 30종 일반·체험 성장 완료와 저장 왕복, 이전 18종 완성본 마이그레이션, 다음 서식지 잠금, 전체 만남의 중복 방지, 데이터·에셋 일치를 확인했다. 도감 그림은 실제 에셋으로 생성해 시각 확인했다. 새 12종의 네이티브 GUI 플레이테스트와 장시간 실행은 별도 검증이 필요하다.

120종은 장기 목표이며 이번 구현은 30종이다. 공개 Pages 배포와 GitHub 설치 파일 릴리스는 별도다.
