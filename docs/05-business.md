# 사업·검증·수익화

## 초기 고객과 홍보

초기 타깃 가설: 컴퓨터에서 오래 작업하고 작고 귀여운 수집 요소를 좋아하는 개발자·디자이너·학생. ‘도트 반려동물’과 ‘알에서 자라는 신화 생물’ 메시지를 비교한다. 알려진 IP 팬덤을 빌리지 않고 읽기 쉬운 이름과 부화 장면으로 제품을 설명한다.

15초 영상 구성: 작은 알 흔들림 → 아기 페가수스 → 실제 작업 화면 옆의 작은 크기 → 성장한 페가수스과 3종 도감. 메인 문구: **일하는 동안, 작은 전설이 깨어납니다.** 원화 확대만으로 홍보하지 않고 실제 표시 크기를 보여준다.

공유는 도감 3종 완성 카드 또는 ‘내 첫 동료’ 카드. 코드/문서/사이트/사용 비용을 담지 않는다. 분석은 기본 탑재하지 않고 알파 참여자가 동의한 설문·수동 로그로 시작한다. 외부 홍보·작가 연락은 이 기획 작업에서 발송하지 않는다.

## 벤치마크

공식 소개를 참고한 대상이며 직접 플레이/매출 검증은 아직 없다.

- Whimside: https://whimside.com/faq/ — 작은 영역의 수집과 지속 동기. 교배나 많은 상호작용을 그대로 가져오지 않음.
- Spirit City: https://mooncubegames.com/home/spirit-city-lofi-sessions-press-kit/ — 집중을 방해하지 않는 발견과 분위기.
- Weyrdlets: https://store.steampowered.com/app/2366060/Weyrdlets__Idle_Desktop_Pets/ — 동료 행동과 데스크톱 배치.
- PokeTokenBar: https://github.com/chattymin/PokeTokenBar — 일상 작업에 연결되는 성장. 기존 캐릭터나 토큰 소모를 필수로 하지 않음.

차별화 가설: 오리지널 도트 + 이해하기 쉬운 전설 생물 + 단순한 알/성장 + 계정 없이 로컬에서 동작. 기능 목록만으로 경쟁력이 입증되는 것은 아니다.

## 검증

1. 5~8명에게 32px 및 실제 확대 크기의 3종 보여주기. 설명 없이 페가수스/세 머리인지 판독되는지, 어느 알을 고르는지 확인.
2. 5명 조작 테스트. 4명 이상이 도움 없이 첫 알→부화→다음 행동을 이해하는 것을 내부 진행 기준으로 사용.
3. 15~20명, 7일 알파. 첫 부화 완료, 첫 성장, 둘째 알 선택, 재실행 여부, 동료를 숨긴 이유를 동의 범위에서 조사.
4. 3종 완료 후 ‘더 모으고 싶은가’와 가격 의향 확인. 클릭/칭찬/설치/결제는 각각 다른 지표로 기록.

이 기준은 업계 벤치마크나 통계적 유의성을 주장하지 않는 소표본 내부 게이트다. 둘째 날 자발적 재실행이 20명 중 10명보다 적다면 종 수를 늘리기 전에 반복 흐름을 수정한다. 3종 판독 실패 시 더 많은 종을 그리지 않는다.

## 수익화 후보

3종 체험 → 10종 기본판 일회성 구매 → 후속 컬렉션 확장팩. 유료 전환과 가격은 아직 미확정. 가격 인터뷰 후보만 9,900/14,900/19,900원으로 놓고 실제 결제 수요로 오해하지 않는다.

기본판 후보: 체험 3종을 포함한 총 10종, 추가 배경·기본 꾸미기. 체험에서 얻은 동료와 세이브를 유지한다. 확장팩은 포함 종 수를 공개하고 알 단위 확률형 판매를 하지 않는다. 구독과 서버 비용이 필요한 기능은 가치 검증 전 보류.

단위 공헌이익 = 세금/환불 조정 후 수입 - 채널 수수료 - 변동비 - 계약 로열티(있다면).
손익분기 판매 수 = 고정 제작비 / 양의 단위 공헌이익. 현재 비용 견적과 구매 데이터가 없어 수익을 예측하지 않는다.

## 비용 통제

MVP 14개의 기본 프레임은 배경/UI/아이콘/QA를 포함한 전체 작업량이 아니다. 10종 확장은 공통 알 2 + 10×2×2 = 42 기본 프레임, 추가 종별 알·변형·특수 동작은 별도. 어려운 종(세 머리·여덟 다리·아홉 꼬리)의 수정비도 고려한다. AI 시안은 방향 탐색용이며 일관된 스프라이트를 자동 보장하지 않는다.

매각 대비: 원본/계약/음원/서체/코드 출처와 라이선스 기록을 유지. 외주 계약에 수정·앱/마케팅 사용·사업 양도 범위를 정한다. 특정 회사의 인수 가능성은 확인하지 않았다.
