# Lorehatch project guidance

- This is a Korean-language planning repository. Do not claim that an app or customer validation exists until verified.
- Brand Lorehatch is provisional; name screening is not trademark clearance.
- Preserve separation of documented tradition, fictional adaptation, and individual observations.
- Never copy third-party game artwork, sprites, source prose, sounds, or logos into this repository without explicit rights.
- Creature stages are not separate species in public counts.
- Prefer local-first, low-interruption experiences; no task-content, keystroke, or clipboard collection by default.
- Implement a scoped vertical slice before expanding the bestiary. Preserve source IDs when updating content.
- No automatic deployment, purchase, external outreach, or licensing claims from the planning documents.
