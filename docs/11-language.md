# 용어·UI 문구

2026-10-27 · v0.3 · 화면 문구의 기준 문서

## 벤치마크 근거

- 포켓몬 공식 도감: 메뉴를 ‘도감’으로 직접 표기. https://www.pokemonkorea.co.kr/pokedex
- Pokémon GO 공식 도움말: ‘알 부화’, ‘파트너’, ‘박스’ 등 기능을 나타내는 명사를 사용. https://niantic.helpshift.com/hc/ko/6-pokemon-go/?l=ko&p=web
- 다마고치 Connection 공식 영문 설명서: egg → baby → child → teenager → adult, growth/care로 설명. 한국어 공식 번역을 확인한 것은 아니며, 우리 단계의 ‘아기/성장’은 자체 선택이다. https://tamagotchi-official.com/manual/toy/connection/connection_web_manual_IS_EN.pdf

공식 안내의 명명 방식을 참고했으며 사용자 친숙도를 정량 검증한 것은 아니다. 브랜드명·고유 재화·아이콘·문장 전체를 복제하지 않는다.

## 사용 용어

- 생물: **펫**. 세계관 소개에서만 환수라는 말을 사용할 수 있다.
- 알: **알**. 전승의 알, 이야기의 씨앗 같은 별도 명칭 없음.
- 시작: **알 선택** / **집중 시작**.
- 시간 상태: **집중 중** / **일시정지** / **계속하기** / **종료**.
- 알 진행: **부화까지 10분**. 수치는 실제 진행 상태에서 계산.
- 성장 진행: **성장까지 30분**. ‘온기’ 같은 변환 재화 없음.
- 수집 목록: **도감**. 현재 보유한 개체 목록: **내 펫**. 두 기능 구분.
- 화면 옆의 펫: **파트너** / 버튼 **파트너로 설정**.
- 진행을 적용하는 개체: **키우는 펫**. 파트너와 다르면 두 이름을 표시.
- 성장 단계: **아기 / 성장**. 단계 비교 시 **아기 모습 / 성장한 모습**.
- 관련 설명 탭: **정보 / 이야기**. 이야기는 전승 요약·출처와 게임 창작 설정을 구분.
- 별명: **이름 바꾸기**. 종 이름은 바꾸지 않고 개체 이름만 변경.
- 지역 분류: **전체 / 드래곤 / 그리스 / 동아시아 / 북유럽 / 이집트**. 화면에서 ‘전승권 컬렉션’으로 부르지 않음.

## 쓰지 않을 말

전승의 알, 메아리 환수, 온기 은행, 조우, 각성, 공명, 전설의 흔적, 여정 시작. 실제 레벨이 없는데 경험치라고 부르거나, 같은 종의 성장인데 다른 종으로 바뀌는 진화처럼 표현하지 않는다. 친숙함을 이유로 없는 강화·전투·스탯을 추가하지 않는다.

## 이름 원칙과 목록

오리지널은 짧은 이름, 익숙한 신화 생물은 원래 이름, 낯선 모티프는 이해하기 쉬운 표시 이름과 원전명을 함께 사용.

- 숲용 — 초록색 잎날개의 용.
- 불꽃용 — 꼬리에 불씨가 있는 용.
- 페가수스 — 날개 달린 말.
- 케르베로스 — 세 머리 강아지.
- 구미호 — 아홉 꼬리 여우.
- 해태 — 전승 상세 검토 후 한 줄 설명 확정.
- 전령 다람쥐 — 라타토스크. 도감 상세에서 원전명 표시.
- 여덟발 말 — 슬레이프니르. 도감 상세에서 원전명 표시.
- 새벽새 — 베누. 도감 상세에서 원전명 표시.
- 태양 딱정벌레 — 스카라브 모티프.

기존 이미지 속 ‘날개말/세머리 강아지’는 이전 시안의 라벨이다. 이미지 재생성은 이번 문구 수정에 포함하지 않았으며 실제 UI는 이 문서의 이름을 사용한다. 모든 이름의 상표 사용 가능성을 확인했다는 뜻은 아니다.

## 상황별 실제 문구

첫 화면: “첫 번째 펫을 골라주세요.”
알 설명: “집중하는 동안 알이 자랍니다.”
시작 버튼: “집중 시작”
일시정지 안내: “다시 시작하면 이어서 진행돼요.”
부화 완료: “페가수스가 태어났어요!” / 버튼 “확인”
도감 등록: “도감에 등록했어요.”
성장 완료: “페가수스가 다 자랐어요!” / 버튼 “확인”
다음 선택: “다음 알을 골라주세요.”
전체 수집: “펫 3종을 모두 모았어요!”
미보유: “아직 없는 펫”
저장 실패: “저장하지 못했어요. 다시 시도해 주세요.”
일일 한도: “오늘 성장에 반영할 수 있는 시간을 모두 채웠어요. 내일 다시 이어갈 수 있어요.”

위 문구는 상태에 맞춰 노출한다. 오류 원인을 모르면 저장 공간 부족 등으로 단정하지 않는다. 세계관 문구는 도감 설명에만 쓰고 버튼에는 실제 행동을 적는다.
