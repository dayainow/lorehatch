# 펫 모션 — 2026-11-17

## 연출 방향

집중 중에는 작업을 방해하지 않는 작은 끄덕임을 사용한다.
대기 중에는 긴 휴식 사이에 숨쉬기, 두리번거리기, 졸기를 넣는다.
사용자가 눌렀을 때만 폴짝 뛰기, 부비기, 몸 흔들기의 큰 반응을 순서대로 보여준다.

## 현재 구현

- 정원: 대기 19초 주기, 집중 4초 주기, 클릭 반응 1.4초.
- Mac 펫: 0.12초 간격으로 정수 픽셀 이동을 계산한다. 클릭 애교는 2초.
- Mac 한 번 클릭은 기존 집중 시작·정지를 유지한다. 두 번 클릭은 정원 열기, 드래그는 위치 이동이다.
- 웹의 시스템 및 앱 움직임 줄이기 설정에서는 몸동작을 끈다. Mac은 전달된 앱 움직임 설정을 따른다.
- 현재 움직임은 기존 두 프레임에 위치·기울기·압축을 더하는 방식이다. 눈 깜박임, 앞발 인사, 종별 꼬리·날개 관절 애니메이션은 아직 구현하지 않았다.

## 검증 범위

자동 테스트와 웹 빌드를 확인했다. 실제 Mac 재생 속도, 드래그와 클릭의 체감,
모바일 터치 및 장시간 사용의 시각 피로는 별도 플레이테스트가 필요하다.

## 패키징 전 확인 — 2026-11-17

- 전체 30종 × 3단계의 정원 표시와 대기/집중 상태, Mac 전달 키를 자동 검사했다.
- 실제 Swift PixelArt 파서로 182개 SVG(펫 180프레임 + 알 2프레임)를 모두 읽었다.
- Mac 브리지에서 final 단계가 누락된 것을 수정했다.
- 최종 도트의 이동을 SVG 그룹 변환 대신 사각형 좌표에 직접 반영해 웹과 Mac의 해석을 맞췄다.
- 앱에서 동작 줄이기를 바꾸면 바탕화면 펫에도 즉시 전달되도록 수정했다.
- 46개 테스트 통과. 모든 펫이 같은 상태별 몸동작을 공유하며, 종별 관절 애니메이션은 아니다.
