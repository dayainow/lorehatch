# 브랜드·쉬운 이름

## 작업명

한국어 사용자에게는 **환수정원**, 영문/저장소 식별자는 **Lorehatch**를 작업명으로 유지한다. 사용자에게 확정받은 상표가 아니라 기획 추천안이다. ‘환수’가 낯설 수 있으므로 소개 문장을 항상 붙인다: **알에서 태어나는 작은 전설을 키우세요.**

핵심 문구: **일하는 동안, 작은 전설이 깨어납니다.**
제품의 정서는 귀여움·작은 놀라움·함께한 시간. 도감은 수집과 애착의 기록이며 생산성을 평가하거나 실패를 벌주는 도구가 아니다.

## 환수 이름 규칙

- 익숙한 이름은 그대로 사용: 페가수스, 케르베로스, 구미호, 해태. 오리지널 종은 숲용·불꽃용처럼 짧게 이름을 붙인다.
- 짧은 설명은 이름 아래에 표시: 페가수스 / 날개 달린 말, 케르베로스 / 세 머리 강아지. 낯선 원전명은 도감 상세에서 설명한다.
- 성장해도 종 이름 유지: 아기 숲용 → 성장한 숲용. 성장형을 새 종으로 세지 않는다.
- 사용자가 붙이는 개체 별명은 종 이름과 분리.
- 기본 UI에서 ‘메아리 개체’ 같은 세계관 용어를 강요하지 않는다.
- 신화 속 단일 존재와 게임의 여러 개체는 심화 도감에서 구분한다.

## 기존 후보 판단

Lorehatch는 의미와 확장성이 좋지만 한국어 발음/철자 회상이 어려울 수 있다. Mythnook은 이해가 더 어렵다. Mythaven/Mythhaven은 이전 조사에서 유사 이름 사업과 게임을 확인해 제외. 설화원은 동명 관광지 등이 있어 제외. 환수정원은 이번 수정에서 제안했으며 별도 상표·도메인·선행 제품 검색 전이다.

## 디자인 방향

환수는 또렷한 도트, UI 텍스트는 읽기 쉬운 일반 서체. UI 전체를 작은 픽셀 글씨로 만들지 않는다. 이끼색과 따뜻한 바탕색, 소수의 강조색으로 구성한다. 정원은 복잡한 판타지 도시보다 작은 땅과 소품으로 표현한다. 생물의 색과 실루엣이 주인공이다.

브랜드 확정 게이트: 5~8명에게 읽기·뜻 설명·들은 이름 검색을 시키고 혼동을 확인. 이후 KIPRIS/WIPO 및 판매 지역 상표·도메인·스토어 검색. 검색 부재를 사용 허가로 해석하지 않는다.

## v0.3 용어 정책

브랜드명은 아직 작업명이며 새 조어를 추가하지 않는다. 한국어 작업명과 저장소명은 유지하되, 실제 화면은 ‘펫 키우기’라는 기능 설명으로 이해시킨다. 꾸며낸 수식어보다 익숙한 명사와 구체적 동작을 쓴다. 문구와 이름의 기준은 [용어·UI 문구](11-language.md).
