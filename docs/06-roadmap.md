# 개발 순서·완료 기준

담당 인력과 예산이 미정이므로 날짜를 약속하지 않는다. 각 단계가 통과해야 다음 콘텐츠를 늘린다.

## P0 현재: 기획 v0.2

도트/알 부화 중심으로 기획 문서 정합성 확보, 3종 MVP와 10종 목표 분리, 시간 밸런스 가설·에셋 규격·콘셉트 이미지 보관. 앱 완성 아님.

## P1 도트 원본 확정

숲용·날개말·세머리 강아지의 실제 32×32 투명 원본. 아기/성장 각 2프레임, 공통 알 2프레임. 원본과 팔레트 보관. 1×/2×/3×에서 확인.
완료: 규격 검사 통과, 5명 중 4명이 설명 없이 3종을 구분, 머리/다리 구조 확인. 실패하면 팔레트/실루엣을 단순화하고, 32px 유지가 어렵다면 모두 48px로 조정해 예산 재산정.

## P2 단일 흐름 시제품

React 기반 한 화면에서 알 선택→부화→성장→도감까지 구현. 테스트 전용 빠른 시간이 실제 성장 속도로 혼동되지 않게 표시. 데이터는 로컬. 완료: 실제 온기 계산과 전환 저장, 새로 실행해도 유지, 튜토리얼 보상 재지급 없음.

## P3 macOS 호스트 검증

Tauri 후보로 tray·투명 창·드래그·포커스·다중 모니터·Spaces·전체화면·수면 복귀 검증. 기기와 OS, CPU/메모리/동작 여부 기록. 안 되면 호스트 방식 재선정.
완료: 업무 포커스를 빼앗지 않음, 숨김 가능, 수면 중 시간 미적립, 1분 이내 체크포인트 손실 상한, 완료 직전 강제 종료에도 이중 보상 없음. ‘저전력’은 측정 전 주장하지 않음.

## P4 3종 알파

정원·도감·설정·데이터 내보내기/복구. 전승 설명 검토, 접근성, 키보드 조작, 모션 감소. 15~20명 테스트.
완료: 다음 알을 고르는 동기와 실제 방해 이유를 기록. 통과 전 10종 제작/결제 확장 금지.

## P5 10종과 상용화 검토

자료 보류 종 검수, 7종 추가, 실제 제작비와 가격 검증, 설치/제거·서명/공증·환불·지원 준비. 공개 배포와 결제는 별도 실행 단계.

## 의미 있는 테스트

세션 중복 적립, 재시작/수면/시간 변경, 온기 상한, 임계 초과분 보존, 튜토리얼 1회, 성장형 동료와 육성 대상 분리, 미보유 알만 선택, 전체 수집 후 상태, 손상 세이브·구버전 마이그레이션·가져오기 검증. 테스트로 확인된 범위만 완료 보고.
