# 개발 계획과 완료 기준

일정은 담당 인력·아트 견적이 없는 상태에서 확정하지 않는다. 각 단계의 결과를 보고 다음 단계에 투자한다.

## 0. 현재 — 기획 저장소

산출물: 브랜드 후보, 세계관, 6종 초안, 3종 검증 범위, 출처, 제품/사업/개발 게이트. 앱이나 시제품을 만들었다고 보고하지 않는다.

## 1. 이름과 콘텐츠 확정

- Lorehatch 발음·철자 테스트, KIPRIS/WIPO 및 대상 지역 상표/스토어/도메인 검색.
- 뿌리용 원전 검증, 베누·스핑크스 표현 검토.
- 3종 실루엣을 48/96px로 평가. 아트 계약과 원본 소유·사용 범위 확정.
- 완료: 출처가 연결된 3종, 대표 이미지 방향, 임시가 아닌 공개용 이름 결정. 이름 충돌 시 저장소 이름과 문서도 변경.

## 2. 핵심 경험 프로토타입

- React 기반 한 화면: 흔적 → 첫 만남 → 도감 → 다음 세션.
- 임시 이미지임을 표시하고 실제 아트와 섞어 완성품처럼 홍보하지 않음.
- 비주얼 작업 시 저장소의 향후 디자인 가이드와 적용 가능한 디자인 스킬 사용.
- 완료: 5명 중 4명이 도움 없이 첫 만남과 다음 행동을 설명. 내부 소표본 기준.

## 3. macOS 호스트 기술 검증

- tray/투명 창/창 이동/전체화면/다중 모니터/수면 복귀/키보드 포커스/동작 줄이기 확인.
- macOS 버전·기기·CPU/메모리 측정값 기록 후 성능 예산 결정. 측정하지 않고 ‘가볍다’고 표현하지 않음.
- 완료: 업무 입력을 가로채지 않음, 세션 재개 시 보상 중복 없음, 강제 종료 후 세이브 복구, 창을 쉽게 숨길 수 있음.

## 4. 3종 비공개 알파

- 로컬 세이브 버전, 내보내기/가져오기, 데이터 삭제.
- 단계별 확정 발견, 관찰 기록, 소리/알림 설정.
- 의미 있는 검사: 동일 세션 이중 정산 방지, 시간 변경·수면·앱 종료 처리, 저장 마이그레이션, 손상 데이터 복구, 출처/콘텐츠 ID 참조 검증.
- 완료: 15~20명 7일 테스트 결과와 사용자 동의 범위를 기록. 애착보다 방해가 크면 출시 연기.

## 5. 6종 MVP 및 배포 검토

- 최종 아트/음원 권리 확인, 신화 설명 교정, 접근성, 설치/제거, 서명·공증 경로 검증.
- 유료화 이전에 환불·지원·계약 조건·세금/채널 수수료를 실제 대상으로 확인.
- 공개 배포·유료 판매·외부 홍보는 별도 실행 단계. 이 기획 저장소 생성은 제품 배포가 아니다.

## 검토할 주요 결정

브랜드 최종명 / 픽셀 또는 손그림 애니메이션 / macOS 최소 버전 / 유료화 시점 / 로컬 전용 지속 여부 / Chrome 확장 후속 우선순위. 이 결정들이 없어도 단계 1의 조사와 3종 기획 개선은 진행할 수 있다.
