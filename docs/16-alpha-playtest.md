# 공개 알파 사용성 검증안

## 목적과 규모

먼저 5명의 첫 사용 과정을 관찰해 큰 혼동을 찾고, 기존 로드맵의 15~20명 알파로 확대한다. 참여자는 아직 모집하지 않았다. 이 문서는 결과 보고가 아니다. 제보나 참여 요청의 외부 발송은 별도 실행이다.

설문 서비스나 개인정보 폼을 새로 만들지 않는다. 자발적으로 받은 의견을 정리할 때 실명·이메일 대신 P01 같은 임시 참여 코드를 쓰고 작업 내용·키 입력·화면 녹화를 기본 수집하지 않는다.

## 5분 체험 순서

빠른 체험 링크를 전달하고 첫 행동을 설명하지 않는다. ‘펫 한 마리를 부화시키고 성장시킨 뒤, 다른 펫을 키울 준비를 해주세요’라고만 요청한다. 막힌 순간을 기록하고 도움을 줬다면 도움 내용을 함께 남긴다.

1. 첫 알 선택: 첫 행동을 찾았는지, 세 펫 중 선택 이유는 무엇인지.
2. 첫 부화: 첫 알이 즉시 부화하는 것을 이해했는지.
3. 집중 시작: 자동으로 자란다고 생각했는지, 시작 버튼을 찾았는지.
4. 성장 확인: 타이머 완료와 성장 확인의 차이를 이해했는지.
5. 다음 알: 육성 대상과 파트너를 구분하는지.
6. 저장: 새로고침 후 같은 펫이 있는지 확인하게 한다.
7. 공유: 이미지를 저장해 보고 별명·집중 시간이 포함되지 않는다는 안내를 이해했는지 묻는다. 게시를 요구하지 않는다.

체험 모드의 30초 성장을 일반 모드 속도로 오해하지 않았는지 마지막에 확인한다. 탭을 바꾸면 멈추는 규칙도 직접 설명해 보게 한다.

## 기록 양식

참여 코드:
기기·브라우저(선택):
첫 알 선택 / 부화 / 집중 시작 / 성장 확인 / 다음 알: 각각 도움 없음·도움 있음·실패 중 하나
막힌 지점과 사용자 표현:
화면을 벗어나면 멈춘다는 설명을 이해했는지:
다음 알도 키우고 싶은지 / 그 이유:
다시 쓰고 싶을 상황:
실제로 방해가 된 부분:
개선 우선순위:

체험 중 쓴 별명과 저장 파일 자체는 위 기록에 옮기지 않는다.

## 다음 2종 제작으로 넘어갈 기준

5명 중 4명 이상이 도움 없이 첫 부화·집중 시작·성장 확인을 끝내는 것을 1차 기준으로 둔다. 저장 유실·중복 지급은 한 건이라도 재현되면 콘텐츠 확장보다 먼저 수정한다. 두 명 이상이 같은 지점에서 막히면 그 흐름을 먼저 고친다.

‘다음 알도 키우고 싶다’는 답변은 이유와 함께 기록하며, 5명의 선호를 시장 수요나 유지율로 일반화하지 않는다. Star 수와 실제 반복 사용도 구분한다. 15~20명 알파 전 재미·생산성 향상·장기 잔존이 확인됐다고 홍보하지 않는다.

## 실패 시 선택

종 선택이 어려우면 종 수를 늘리기 전에 미리보기와 설명을 고친다. 시작 버튼을 못 찾으면 첫 부화 후 안내를 보강한다. 화면 표시 조건이 맞지 않으면 네이티브 호스트 검증의 우선순위를 높인다. 콘텐츠가 짧다는 의견만으로 성장 시간을 늘리거나 출석 과제를 추가하지 않는다.
