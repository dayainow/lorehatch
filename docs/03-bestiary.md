# 첫 관찰 도감

## 분류 구조

지역 → 전승 모티프 → 환수 종류 → 개체 → 성장 모습 순서로 분리한다. 성장 모습, 색 변형, 개체를 별도 종 수로 광고하지 않는다. 지역을 초월하는 ‘날개/뿔/물가/야행’ 태그는 검색 보조이며 전승을 대체하지 않는다.

개체 성장: 흔적 발견 → 맞이하기 → 어린 모습 → 익숙한 동료 → 관찰 완성. ‘다른 신화 존재로 진화’하지 않고 같은 환수가 성장한다. 모든 존재를 알에서 부화시키지 않는다. 알, 잎 둥지, 빛의 고치, 조약돌 같은 맞이하기 연출은 게임 창작임을 표시한다.

## MVP 6종 — 이름·외형은 기획 가칭

### N01 라타토스크 메아리 / 별명 솔솔

- 전승 근거: Yggdrasil에서 소식을 전달하는 다람쥐. 출처 S01.
- 창작 외형: 커다란 잎꼬리와 작은 씨앗 주머니. 기존 작품의 다람쥐 디자인을 참조하지 않는다.
- 역할: 첫 안내자, 탐방 편지를 가져오는 대표 마스코트.
- 성장: 작고 둥근 어린 모습 → 긴 꼬리와 관찰 주머니를 갖춘 동료. 신체 장식과 행동은 창작.
- 동작: 꼬리 덮고 자기, 주머니에서 씨앗 꺼내기, 짧게 달려 편지 전달.
- 발견: 튜토리얼에서 선택 시 확정 지급. 미선택 시 짧은 가지숲 관찰 과제로 확정.

### N02 슬레이프니르 메아리 / 별명 여덟발

- 전승 근거: 오딘이 타는 여덟 다리 말. 출처 S01.
- 창작 외형: 여덟 발을 둥근 리듬으로 보여주는 작은 안개빛 말.
- 역할: 길 탐험. 큰 보상 배율 대신 새 탐방길 접근 역할.
- 성장: 짧은 갈기 → 바람처럼 흐르는 갈기. 전승상의 생애 묘사가 아님.
- 제작 위험: 작은 화면에서 여덟 다리 가독성과 애니메이션 비용. 축소 시 식별되지 않으면 MVP에서 제외하고 대체 후보 조사.
- 발견: 가지숲의 길 관찰 연쇄를 완료하면 확정. 원전의 탄생 서사는 기본 귀여운 설명에서 임의 왜곡하지 않고 심화 탭 검토.

### N03 뿌리용 메아리 / 별명 뿌룽

- 모티프 후보: Níðhöggr. 세부 원전·신뢰할 자료 교차 확인 전으로 콘텐츠 게이트 보류.
- 창작 외형: 뿌리를 닮은 작은 뿔, 짧은 몸, 이끼가 얹힌 등.
- 역할: 뿌리 틈의 숨은 흔적 찾기.
- 성장: 둥근 어린 용 → 길어진 몸과 뿌리뿔. 식물성 디자인은 창작.
- 검토: 파괴적 원전 맥락을 무해한 정원사였다고 바꾸어 설명하지 않는다.

### E01 베누 메아리 / 별명 여울

- 전승 근거: 이집트의 새 모티프, 재생과 관련된 전승. S02·S03. 세부 신학 관계는 추가 검토.
- 창작 외형: 백로형 긴 목을 유지하되 짧은 다리의 어린 모습, 두 갈래 머리깃, 은은한 새벽빛.
- 역할: 새벽 습지 대표. 현실 시각과 무관하게 게임 내부의 새벽 연출을 선택할 수 있음.
- 성장: 어린 새 → 길어진 목과 펼쳐진 깃. 불타 죽는 연출을 피닉스에서 자동 이식하지 않음.
- 발견: 초기 지역 선택 또는 습지 관찰 과제로 확정.

### E02 스카라브 메아리 / 별명 해굴

- 전승 근거: 스카라브와 태양·재생, 케프리와의 관계. S04·S05.
- 창작 외형: 작은 돌빛 등딱지, 투명한 빛 구슬을 굴리는 딱정벌레.
- 역할: 서식지 꾸미기 재료 운반. 태양신 자체를 소유하는 것으로 설명하지 않음.
- 성장: 둥근 어린 모습 → 날개 무늬와 넓어진 등판.
- 발견: 습지의 빛 흔적 세 종류를 관찰하면 확정. 구체적 횟수는 튜닝 대상.

### E03 스핑크스 메아리 / 별명 모래잠

- 전승 근거: 이집트 스핑크스의 인간 머리·사자 몸, 왕권 상징 맥락. S06.
- 창작 외형: 부드러운 인간형 얼굴과 작은 사자 몸, 돌 같은 질감. 그리스 스핑크스의 날개·수수께끼 설정을 자동 혼합하지 않음.
- 역할: 조용히 머무는 보호구역 동료, 관찰 페이지 안내.
- 성장: 작고 웅크린 모습 → 편안하게 앞발을 뻗은 모습.
- 검토: 귀여운 인간형 얼굴의 매력 및 작은 크기 식별 테스트 필요. 검수 전 완성 디자인으로 간주하지 않음.

## 첫 시제품 3종

솔솔 / 여울 / 해굴. 다람쥐·새·곤충으로 실루엣 차이를 크게 만들고, 제작 부담이 큰 여덟 다리 말과 조사 보류인 뿌리용은 뒤로 미룬다. 먼저 첫 만남과 재방문 동기를 검증한다.

## 도감 한 페이지

1. 게임 이름·개체 별명·지역·성장 모습.
2. ‘내 관찰’: 만난 날, 발견한 행동, 함께한 세션, 사용자가 붙인 별명.
3. ‘전승에서’: 검증된 모티프만 짧게 요약하고 출처 링크.
4. ‘우리의 상상’: 창작 외형·성격·능력을 명시.
5. 다음 발견 단서: 해야 할 행동을 이해할 수 있게 안내. 감추기만 하는 랜덤 수집 금지.

완성 조건은 종 확보뿐 아니라 쉬기·놀기·서식지 반응 등 3개 행동 관찰. 초기 목표 수치이며 실제 대기 시간은 플레이테스트로 조정한다.

## 아트 제작 규격 제안

48/96/192px 표시 크기로 실루엣 검증. 각 형태의 필수 상태는 대기·이동·잠·기쁨 네 가지. MVP 12형태 × 4상태 = 48개 상태 클립으로 예산 산정한다. 클립당 프레임 수·방향 수는 별도이며 아직 작업량을 확정하지 않았다. 종별 특수 행동은 코어 이후 추가한다.
